# Recepción dashboard

- `agenda`: presentación y acciones de las citas del día.
- `quick-appointment`: búsqueda de cliente, captura de cita y selección de horario.
- `waitlist`: seguimiento y notificación de clientes en espera.
- `forms`: contratos de los formularios de Recepción.
- El componente raíz conserva la coordinación del contexto, navegación y carga de datos.
- El panel lateral coordina los componentes operativos sin contener sus plantillas.

Los estados, etiquetas y transiciones habilitadas deben provenir del catálogo del backend.
