# Playfair Display para sitios de negocio

Fuente oficial de Google Fonts, hoja v40 obtenida el 2026-10-19 desde `https://fonts.googleapis.com/css2?family=Playfair+Display:wght@700&display=swap` (misma familia/peso que la hoja anterior compartida con Poppins). Binarios WOFF2 oficiales de `fonts.gstatic.com/s/playfairdisplay/v40/`.

Se conservan los cuatro subconjuntos (cyrillic, vietnamese, latin-ext, latin), sus `unicode-range`, estilo normal, peso 700 y `font-display: swap`. El nombre de familia sigue siendo `Playfair Display`. Las reglas están en `tenant-fonts.css`, compartido por ambas entradas. Sin precarga: solo se descarga cuando la configuración existente del sitio o su vista previa usa esta familia. No se incluyen fuentes adicionales ni se cambia la selección del tenant.

Licencia SIL OFL 1.1 en `PlayfairDisplay-OFL.txt`, obtenida del repositorio oficial `google/fonts`, directorio `ofl/playfairdisplay/OFL.txt`. Poppins se retiró de ambas entradas tras comprobar que ningún selector o configuración de fuente del proyecto la utiliza.
